# T5 · Аудит исключений (без изменения кода)

Не меняя код, найди в пакете `minishop` все функции и методы, которые могут выбросить исключение
(явно или из вызываемого кода/стандартной библиотеки при некорректных входных данных).
Создай файл `ANSWER.md`: по одной строке на пару «функция — исключение» в формате

`модуль.Класс.метод: ИмяИсключения — условие` (для функций без класса — `модуль.функция: ...`).

Например: `pricing.line_total: ValueError — qty < 0`. Других файлов не создавай и не меняй.

---
Правила: работай только в этой копии репозитория, ничего не пушь. Можно запускать тесты: `python -m unittest discover -s tests`.
В конце кратко (3–5 строк) опиши, что сделал.
