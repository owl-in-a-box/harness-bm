# T4 · Учёт остатков

Добавь учёт остатков товара:
1. `Product` получает поле `stock: int | None = None` (`None` — запас не ограничен). Существующий код,
   создающий `Product` без `stock`, должен работать как раньше.
2. В `minishop/catalog.py` — исключение `OutOfStock(Exception)` и метод `Catalog.restock(sku, n)`:
   увеличивает остаток на `n`; `n <= 0` → `ValueError`; товар с `stock=None` после `restock` остаётся неограниченным.
3. `Cart.add` выбрасывает `OutOfStock`, если суммарное количество товара в корзине превысит остаток;
   при ошибке корзина не меняется. `qty <= 0` → `ValueError`.
