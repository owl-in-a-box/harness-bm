# T6 · CLI-сводка по каталогу

Добавь модуль `minishop/cli.py`, запускаемый как `python -m minishop.cli summary <path>`, где `<path>` — JSON-файл
со списком объектов `{"sku": str, "name": str, "price": str, "stock": int}`.

Вывод в stdout — **ровно одна строка** JSON, полученная как
`json.dumps(obj, sort_keys=True, separators=(",", ":"))`, где `obj` = `{"count": <число товаров>, "skus": <отсортированный список sku>,
"total_value": <сумма price*stock строкой с двумя знаками, напр. "12.50">}`. Код выхода 0.
Если файл не найден или JSON некорректен — ничего в stdout, в stderr одна строка, начинающаяся с `error: `, код выхода 2.

Ограничения: не меняй `pricing.py`, `report.py` и каталог `tests/`; только стандартная библиотека.
