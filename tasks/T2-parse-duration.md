# T2 · Разбор длительности

Создай модуль `minishop/duration.py` с функцией `parse_duration(text: str) -> int`, возвращающей число секунд.

Формат: необязательные части `<число>h`, `<число>m`, `<число>s` строго в этом порядке, каждая не больше одного раза,
хотя бы одна часть обязательна. Числа — целые неотрицательные (без знака и дробей). Регистр букв не важен,
пробелы по краям игнорируются, пробелы внутри запрещены.
Примеры: `"1h30m"` → 5400, `"45s"` → 45, `"2H"` → 7200, `"1h5s"` → 3605, `" 0s "` → 0.
Любая другая строка (`""`, `"5"`, `"1m1h"`, `"1.5h"`, `"1h 30m"`, `"-1m"`, `"1hh"`) → `ValueError`. Не строка → `TypeError`.
